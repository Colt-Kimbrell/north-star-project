# The North Star Project

*The North Star Project* is an interactive work of electronic literature
presented as a recovered astronomical research archive.

The narrative is constructed through observation logs, personnel records,
photographs, transcripts, corrupted files, and system messages. The interface
itself forms part of the narrative, with reader interaction and persistent
browser state affecting the archive across visits.

## Disclaimer

*The North Star Project* is a fictional work of electronic literature.
Historical institutions, archival collections, photographs, and astronomical
materials used as source imagery should not be understood as documenting or
participating in the fictional events depicted in the work.
